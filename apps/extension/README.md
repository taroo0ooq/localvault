# LocalVault Browser Extension (S5, MV3)

Features:
- **Autofill** — match vault items by page origin; chip + context menu + popup
- **Autosave** — detect password submit/change; badge + confirm in popup
- **Generate & fill** — CSPRNG password into password field

```bash
npm run build --workspace=@localvault/extension
npm test --workspace=@localvault/extension
```

See `docs/s5/load-unpacked.md` and `docs/s5/permission-audit.md`.
